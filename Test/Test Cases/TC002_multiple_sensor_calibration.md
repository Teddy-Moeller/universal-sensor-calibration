## Objective

Verify that Universal Sensor Calibration can monitor and calibrate multiple sensors simultaneously while maintaining stable Home Assistant operation.

A minimum of 30 configured sensors is recommended for meaningful test coverage.

## Steps

1. Establish a Home Assistant baseline by observing normal system behaviour for at least one hour.

2. Configure multiple sensors in `calibration.yaml`.

   Note:
   For testing purposes an offset of `0` may be used.

3. Restart Home Assistant.

4. Allow the system to run for at least one hour.

5. Establish a new baseline.

6. Compare the new baseline against the original baseline.

7. Document any observed changes in Home Assistant behaviour.

## Expected Result
(Checked means passed)

- [ ] All configured sensors continue to update correctly.
- [ ] Home Assistant remains responsive.
- [ ] No calibration loops are observed.
- [ ] No unexpected errors are generated by Universal Sensor Calibration.
- [ ] No significant degradation in Home Assistant performance is observed.
- [ ] No significant degradation in supporting infrastructure is observed.
